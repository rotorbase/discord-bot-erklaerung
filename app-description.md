# Hermes Agent — Discord-Bot Beschreibung

**Kurze Beschreibung (für Discord-Portal „Description"-Feld):**

> Hermes Agent ist ein privater KI-Assistent für VTOL-Drohnen-Operationen: Sucheinsätze (SAR), Wildschutz und kommerzielle Inspektion. Er verbindet sich mit einem selbst gehosteten Sprachmodell-Backend und gewährt dem verifizierten Entwickler vollen Tool-Zugriff (Terminal, Dateien, Web, Browser).

**Tags / Kategorien:** Produktivität, Entwicklertools, Drohnen, Luftfahrt
